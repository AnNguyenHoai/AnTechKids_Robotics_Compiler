# H25-D — Firmware Feature Guard

## Implemented features
This task connects the generated H25-C hardware macros to firmware behavior for:

- `ROBOT_FEATURE_IMU`
- `ROBOT_FEATURE_ENCODER`

## IMU OFF
When `ROBOT_FEATURE_IMU == 0`:

- MPU6050 sensor headers and registration are excluded.
- No IMU initialization or automatic gyro calibration is performed.
- Startup cannot halt because the optional IMU is absent.
- Heading hold is disabled.
- `Forward()` and `Backward()` remain available and run with direct motor output without IMU correction.
- The robot enters READY state normally.

## Encoder OFF
When `ROBOT_FEATURE_ENCODER == 0`:

- Encoder objects are not created.
- GPIO interrupts are not attached.
- Encoder APIs remain link-compatible and return neutral values or no-op.
- Existing firmware code can run without encoder hardware.

## Scope intentionally deferred
Macros for line sensor, ultrasonic, motor, servo and buzzer are still generated by H25-C but are not connected to firmware guards in this task.
