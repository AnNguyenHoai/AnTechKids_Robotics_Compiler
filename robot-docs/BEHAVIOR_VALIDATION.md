# Behavior Validation

## Validation Framework
Chạy `python robot-platform/validation/behavior_validation.py` để thực hiện tất cả golden behaviors.

## Golden Behaviors
- MoveForward
- TouchStop
- ObstacleStop
- Wait
- LineDetect
- ColorDetect

## Acceptance Criteria
- Mỗi behavior hoàn thành đúng trạng thái.
- Không crash.
- Log đầy đủ.
- Thời gian phản hồi trong ngưỡng cho phép.
