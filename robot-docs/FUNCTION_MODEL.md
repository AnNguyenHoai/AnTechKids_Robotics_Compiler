# Function Model

## Declaration
- Tên hàm phải là snake_case.
- Tham số được đặt tên.
- Hàm có thể có hoặc không có giá trị trả về.

## Invocation
- Gọi hàm bằng tên, truyền đúng số lượng đối số.
- Đối số được đánh giá trước khi gọi.

## Call Stack
- VM sử dụng call stack để lưu địa chỉ trả về.
- Độ sâu tối đa: 8.

## Return Value
- Giá trị trả về được lưu tại biến index 0.
