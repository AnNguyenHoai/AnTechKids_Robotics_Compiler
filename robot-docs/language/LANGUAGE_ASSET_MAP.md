# Language Asset Map

**Version:** 1.0  
**Status:** Architecture Freeze  
**Date:** 2026-08-09

## Overview

This document maps every language-related asset in the Robot Development Platform, identifying whether it is a **Source** (manually maintained) or **Generated** (produced by the build system).

---

## Asset Classification

| Asset | Type | Owner | Generated From |
|-------|------|-------|----------------|
| `api.yaml` | **SOURCE** | Language Architect | N/A |
| `opcode.py` | Generated | Compiler | api.yaml |
| `opcode.h` | Generated | Platform/VM | api.yaml |
| `opcode.json` | Generated | Tooling | api.yaml |
| `function_registry.py` | Generated | Compiler | api.yaml |
| `registry.json` | Generated | Tooling | api.yaml |
| `robot/*.py` (SDK) | Generated | Frontend/Users | api.yaml |
| `docs/generated/*.md` | Generated | Documentation | api.yaml |
| `compiler/handlers/*.py` | **SOURCE** | Compiler Team | N/A |
| `frontend/transformer.py` | **SOURCE** | Frontend Team | N/A |

---

## Source Files (Manual)

These files are manually maintained and are the **only** files developers should edit when adding or modifying language features:

| File | Purpose |
|------|---------|
| `robot-language/specification/api.yaml` | Master language definition |
| `robot-compiler/compiler/handlers/*.py` | Compiler handler implementations |
| `robot-frontend-robosim/frontend/transformer.py` | AST transformation rules |
| `robot-frontend-robosim/frontend/mapping.py` | API mapping rules |

---

## Generated Files (Auto)

These files are automatically generated by the build system. **DO NOT EDIT MANUALLY:**

| File | Location | Generator |
|------|----------|-----------|
| `opcode.py` | `robot-compiler/compiler/generated/` | OpcodeGenerator |
| `opcode.h` | `robot-platform/main/include/generated/` | OpcodeHeaderGenerator |
| `opcode.json` | `robot-language/generated/` | OpcodeJsonGenerator |
| `function_registry.py` | `robot-compiler/compiler/generated/` | RegistryGenerator |
| `registry.json` | `robot-language/generated/` | RegistryJsonGenerator |
| `robot/*.py` | `robot-language/robot/` | SDKGenerator |
| `*.md` | `robot-docs/generated/` | DocGenerator |

## File Header Requirements

Every generated file MUST contain this header:

```python
"""
AUTO GENERATED FILE
DO NOT EDIT MANUALLY
Generated from: api.yaml
"""
Or for C++:

cpp
/******************************************************************************
 * AUTO GENERATED FILE
 * DO NOT EDIT MANUALLY
 * Generated from: api.yaml
 ******************************************************************************/
Ownership Rules
Language Architect
Owns api.yaml

Responsible for language evolution

Validates semantic consistency

Compiler Team
Owns compiler/handlers/*.py

Implements API handlers

Uses generated registry for dispatch

Frontend Team
Owns frontend/transformer.py

Owns frontend/mapping.py

Implements rewrite rules

Build System
Owns all generated files

Ensures deterministic generation

Validates output

Change Flow
When adding a new language feature:

Edit api.yaml (add function, opcode, semantic)

Run build → regenerates all artifacts

Implement handler in appropriate handlers/*.py

Add rewrite rule in frontend/transformer.py (if needed)

Add test in tests/compatibility/

Run full validation

Never: Edit generated files directly.

Validation Before Generation
The build system MUST run these validators before generating artifacts:

Syntax Validator – YAML structure

Duplicate Validator – No duplicate names/IDs

Reference Validator – All references valid

Semantic Validator – Semantic classification valid

If any validator fails, generation stops.
