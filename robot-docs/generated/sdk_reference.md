# SDK Reference (Python)

This document describes the Python SDK generated from the specification.

## Installation
The SDK is automatically installed as part of the `robot-language` build.

## API Reference

### Motion
#### `forward(speed)`
- Move robot forward

#### `backward(speed)`
- Move robot backward

#### `turn_left(speed)`
- Rotate robot left

#### `turn_right(speed)`
- Rotate robot right

### System
#### `wait(milliseconds)`
- Wait milliseconds

#### `stop()`
- Stop robot
