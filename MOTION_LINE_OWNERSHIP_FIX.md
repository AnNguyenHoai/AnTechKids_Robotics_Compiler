# Motion / Line Control Ownership Fix

## Objective
Prevent IMU heading hold from overriding motor commands generated by line following.

## Behavior
- `Forward()` / `Backward()` enter `HEADING` control mode.
- All line APIs enter `LINE` control mode.
- Entering `LINE` mode stops `HeadingController` and clears the normal motion state.
- `updateMotion()` executes `_applyMotion()` only in `HEADING` mode.
- IMU runtime updates are not disabled; only IMU-to-motor heading correction is disabled during line control.
- `Stop()` returns ownership to `NONE`.

## Affected Line APIs
- `LineBasis`
- `LineFollow` (via `LineBasis`)
- `LineMillisecond`
- `LineIntersectionStop`
- `LineTurnEncounterLine`
- `LineForBmp`

## Expected diagnostic transition
```
[MOTION-MODE] LINE: heading control disabled, line sensors own motor steering
```
