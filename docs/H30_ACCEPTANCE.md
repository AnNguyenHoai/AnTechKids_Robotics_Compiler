# H30 Acceptance Outcomes

H30 is ready for review when:

- H30 regression gate passes;
- repository regression suite passes;
- Windows production ZIP build passes;
- no production flow uses robot list position as robot identity;
- persistent registry is external to immutable release files;
- physical two-robot checklist is ready for execution.

Merge/release acceptance additionally requires the physical multi-robot checklist to pass on real robots.
