# H27-B0 — First-Flash Wi-Fi Bootstrap

## Purpose

Prepare a new ESP32 robot for RoboStudio without requiring PlatformIO on the teacher's machine.

The first USB flash uses an Arduino IDE sketch generated by RoboStudio. The generated sketch contains the classroom Wi-Fi and OTA credentials locally. It connects to Wi-Fi, advertises the canonical robot identity, supports discovery, and accepts the next firmware image over ArduinoOTA.

## Teacher flow

1. Open **RoboStudio → Robot → First-Flash Setup**.
2. Enter the classroom Wi-Fi SSID, Wi-Fi password, and an OTA password.
3. Click **Generate Arduino IDE Package**.
4. Open the generated `FirstFlash.ino` in Arduino IDE.
5. Select **ESP32 Dev Module** and the robot's USB/COM port.
6. Click **Upload**.
7. Power/reboot the robot if requested and wait for the serial log:
   - `[BOOTSTRAP] READY`
   - `[BOOTSTRAP] IP: ...`
   - `[BOOTSTRAP] OTA: robot-XXXXXX.local`
8. Return to RoboStudio and click **Discover Robots**.
9. Select the robot and use the normal OTA deployment flow.

## What the first-flash sketch does

```text
Arduino IDE USB upload
        ↓
FirstFlash bootstrap firmware
        ↓
Connect classroom Wi-Fi
        ↓
Expose /api/v1/health and /api/v1/info
        ↓
Respond to H27-A discovery on UDP 4210
        ↓
Accept normal robot firmware over ArduinoOTA
```

The bootstrap sketch is intentionally small. It does not execute the student's robot program; it exists only to establish network connectivity and OTA capability for a new device.

## Credentials

The generated `bootstrap_secrets.h` is local-only and is written under `.robostudio/`. The repository `.gitignore` already excludes `.robostudio/`.

Do not commit generated first-flash packages or Wi-Fi/OTA credentials.

## Why Arduino IDE is the recovery/first-flash path

RoboStudio's normal deployment pipeline can continue to use PlatformIO internally for the canonical firmware build. Arduino IDE is only the teacher-friendly USB bootstrap path. After the robot is online, the intended classroom flow is:

```text
Discover → Select → Compile → OTA → Verify → Run
```
